📋 Próximos pasos para el usuario
1. Configurar MySQL
# Iniciar MySQL y ejecutar:
mysql -u root -p < scripts_sql/crear_bd.sql
2. Ajustar credenciales en utils/db_config.py
DB_CONFIG = {
    "host": "localhost",
    "port": 3306,
    "user": "tu_usuario",      # ej: root
    "password": "tu_password", # tu contraseña
    "database": "cariodetector",
    ...
}
3. Colocar el modelo YOLO
# Copiar tu modelo entrenado a:
models/best_24_chromosomes.pt
El modelo debe ser YOLOv8/v11 (Ultralytics) entrenado para 24 clases en el orden: cromosoma 1..22, X, Y
4. Ejecutar
python main.py
🎯 Funcionalidades implementadas
Módulo	Responsabilidad
main.py	Entry point, verificaciones básicas
interfaz/interfaz.py	GUI completa: seleccionar imagen, analizar, mostrar original/resultado, tabla detecciones, resumen, guardar en MySQL, historial
funciones/analisis_imagen.py	OOP - AnalizadorImagen: cargar imagen, ejecutar detección, dibujar boxes, generar imagen anotada
funciones/modelo_cromosomas.py	DetectorCromosomas: cargar .pt, inferencia, normalizar detecciones
funciones/resultados.py	Funciones puras: tabla, resumen, stats, formato BD
utils/db_config.py	Conexión MySQL, test conexión, inicializar BD desde SQL
scripts_sql/crear_bd.sql	Tablas analisis + detecciones + índices + vista
⚠️ Manejo de errores incluido
- Imagen no seleccionada / inválida
- Modelo no encontrado (mensaje claro con ruta)
- Error cargando modelo
- Error durante inferencia
- MySQL no disponible (credenciales, servidor caído)
